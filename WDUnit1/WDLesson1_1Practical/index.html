Web Technology

h3 Html is the standard markup language for creating web pages. It uses elements and tags to define the structure and content of a page. Browsers read HTML code to display text, image, links, and other content on the web.

CSS

CSS is Cascading Style Sheets, a stylesheet language used to control the presentation and layout of HTML or XML documents. CSS is a declarative language that defines how elements on a webpage should look—such as colors, fonts, spacing, and layout. Browsers apply CSS rules to selected elements to render pages visually.

JavaScript

JavaScript is a programming language that is commonly used to create interactive effects within web browsers. It is a high-level, interpreted language that runs on the client-side of a webpage. JavaScript can manipulate HTML and CSS to create dynamic content and respond to user interactions.

ReactJS

ReactJS is a JavaScript library for building user interfaces, particularly single-page applications. It allows developers to create reusable UI components and manage the state of their applications efficiently. React uses a virtual DOM to optimize rendering and improve performance, making it a popular choice for modern web development.
