Web Technology

Html is the standard markup language for creating web pages. It uses elements and tags to define the structure and content of a page. Browsers read HTML code to display text, image, links, and other content on the web.

CSS CSS is Cascading Style Sheets, a stylesheet language used to control the presentation and layout of HTML or XML documents. CSS is a declarative language that defines how elements on a webpage should look—such as colors, fonts, spacing, and layout. Browsers apply CSS rules to selected elements to render pages visually
